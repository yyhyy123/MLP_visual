误差与梯度

δ → loss → Adam

δ = ŷ − y—
L = −[y ln ŷ + (1−y)ln(1−ŷ)]—
全批量 ∂L/∂c = mean(δ)—
δ、L 取自选中样本；梯度取 4 个样本平均。两层梯度汇合后交给 Adam。

误差继续向前传。输出端的 δ 经 v 和 Sigmoid 导数传回隐藏层，得到 W₁ 与 b₁ 的梯度；Adam 根据全部 9 个梯度更新参数，模型随即进入下一轮。

Minimal implementation

核心实现，与页面计算一一对应

Python 
# X: 4×2，Y: 4×1；一次全批量前向 + 反向
Z = X @ W1 + b1
H = sigmoid(Z)
P = sigmoid(H @ v + c)

loss = -np.mean(Y*np.log(P) + (1-Y)*np.log(1-P))

d_out = (P - Y) / len(X)
dv = H.T @ d_out
dc = d_out.sum(axis=0)
d_hidden = (d_out @ v.T) * H * (1 - H)
dW1 = X.T @ d_hidden
db1 = d_hidden.sum(axis=0)

# Adam 用 dW1, db1, dv, dc 更新 9 个参数

Field notes

读图提示

  1. 01

    先看边界。训练早期权重很小，模型几乎还分不开两类；随着权重变大，决策区域才逐渐折出 XOR 需要的非线性形状。

  2. 02

    再看连线。蓝色是正权重，橙色是负权重，线越粗绝对值越大。选中不同样本时，节点里的激活值会变化，但权重保持不变。

  3. 03

    最后看损失。悬停曲线读取任意轮次，点击即可跳转。学习率切到 0.01，下降会明显更慢，但最终仍能学会。

为什么一定要隐藏层？
单个线性分类器只能画一条直线，无法把 XOR 的两组对角样本分开。两个隐藏节点先把输入映射到新的特征，再由输出层组合，才形成真正的非线性边界。
